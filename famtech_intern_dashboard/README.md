# FAMTECH Intern Dashboard

## Overview
The FAMTECH Intern Dashboard is a custom Odoo 18 module built for FAMTECH Innovative IT Solutions to support intern monitoring, engagement, and reporting in a single workflow. It brings onboarding, metrics and KPI tracking, rewards, and exportable insights together, allowing both interns and HR teams to work from one connected system. The project is designed to improve visibility into intern progress while making routine tracking and follow-up more efficient.

This project extends Odoo's HR, Project, Calendar, Website, and Portal capabilities to create a focused internship management experience. It supports internal HR operations through backend dashboards and reports, while also providing interns with a website-based experience for onboarding, performance visibility, rewards, and attendance-related actions.

## Tech Stack

### Frontend

- XML and QWeb templates
- OWL JavaScript components
- Chart.js
- Bootstrap 5
- SCSS and CSS

### Backend

- Odoo 18
- Python
- Odoo ORM and HTTP controllers

### Database

- PostgreSQL through the Odoo platform

## Key Features

- Automatic calculation and display of intern performance metrics, including KPI scores, average score, and rendered-hours progress.
- Automated email notifications for managers and HR when an intern completes required hours, has 50 hours remaining, or falls below the performance threshold.
- Intern dashboard with metric cards, progress visuals, a Timeliness vs Responsiveness chart, and report export.
- Onboarding page with a step-by-step checklist, completion status, progress tracking, and quick links to the handbook, calendar, profile, and tasks.
- Calendar page with meeting search, filter, sort, and oldest/newest order controls, plus actions for joining or logging attendance.
- Rewards page featuring the weekly winner, top intern rankings, progress summary, badges, vouchers, and winner history.
- HR monitoring tools for intern KPI overview, evaluation records, graphs, and report generation.
